SmartStock Lite v1.5
วิธีใช้: Google Sheet > ส่วนขยาย > Apps Script > วางไฟล์ Code.gs, Index.html, appsscript.json > Deploy เป็น Web app
ชีต Products/Purchases จะถูกสร้างอัตโนมัติเมื่อเปิดใช้งานครั้งแรก
Changelog: v1.4 - สร้างธีมและหน้าจอทั้งหมด
v1.4 - Header: เอาโปรไฟล์ออก เพิ่มปุ่มรีเฟรช; หน้าแรก/สินค้า/วิเคราะห์ = Coming soon; ย้ายปุ่มเพิ่มสินค้าไปหน้าจัดการข้อมูล
v1.4 - หน้า "ซื้อสินค้า" (เดิม บันทึกซื้อ): ใช้ฟิลด์ระบบเก่า (ร้านค้า/วันที่/เลขที่คำสั่งซื้อ/หลายสินค้า/หน่วยซื้อ-เรโช-หน่วยขาย/ค่าส่ง/ส่วนลด/หมายเหตุ) บันทึกลงชีต Purchases, ProductGroups, Categories, Stores, Units โครงสร้างเดียวกับระบบเก่า
v1.4 - เพิ่ม OCR อ่านรูปคำสั่งซื้อ, อัปโหลดรูปใบเสร็จ/บิล (Google Drive), ประวัติซื้อ (แก้ไข/ยกเลิก/กู้คืน); ตัดเรื่องสต๊อกออก (ลบชีต Products, ตัวเลขแจ้งเตือนสินค้าใกล้หมด); หน้าจัดการข้อมูล = จัดการกลุ่มสินค้า
หมายเหตุ: ต้องอนุญาตสิทธิ์ Google Drive ตอน Deploy (สำหรับรูปใบเสร็จ/บิล)
v1.4 - จัดการข้อมูลตรงกับระบบเก่า: แท็บ หมวดสินค้าหลัก/กลุ่มสินค้า/ร้านค้า/หน่วยซื้อ/หน่วยขาย, เปลี่ยนชื่อ, เปิด-ปิดใช้งาน, ลบ (เมื่อไม่มีการใช้งาน), รวมรายการซ้ำ, ย้ายกลุ่มสินค้าไปหมวดอื่น, เพิ่มหมวด/ร้าน/หน่วย
v1.5 - OCR: สร้างหน้าอ่านรูปใหม่ (github-pages/ocr-reader.html) ธีมเดียวกับระบบใหม่ และเปลี่ยน GitHub Pages เป็น https://kunjay-eng.github.io/SmartStockLite (Index.html: OCR_URL)
v1.5 - OCR เร็วขึ้น: ย่อรูปอัตโนมัติทันทีที่เลือก, ปิดโหมดคิดยาวของโมเดล, รับผลแบบ streaming, ตั้งเวลารอ (30 วินาที/โมเดล, รวมไม่เกิน 100 วินาที) แล้วสลับโมเดลสำรองอัตโนมัติ
v1.5 - OCR แจ้งสถานะทีละขั้น (เตรียมรูป > ส่งรูป/รอ AI > AI เขียนผลลัพธ์ > ตรวจผล) พร้อมเวลาที่ใช้ ปุ่มยกเลิก และแจ้ง error ละเอียด (สาเหตุ วิธีแก้ ปุ่มลองอีกครั้ง/คัดลอก error)
วิธีติดตั้ง OCR: อัปโหลด github-pages/ocr-reader.html ไปไว้ที่ root ของ repo SmartStockLite บน GitHub (ชื่อไฟล์ ocr-reader.html) แล้วรอ GitHub Pages อัปเดต 1-2 นาที; Index.html ต้องวางทับใน Apps Script แล้ว Deploy ใหม่
v1.6 - หน้าจัดการข้อมูลเร็วขึ้น: รวมการเรียกเซิร์ฟเวอร์เป็นรอบเดียว (getMasterBundle), กรองหมวดฝั่งเครื่องไม่ต้องโหลดใหม่, แคชรายการและแสดงทันทีที่เปิดซ้ำ (อัปเดตเบื้องหลัง), ไม่โหลดตัวเลือกหน้าซื้อซ้ำทุกครั้งที่แก้ไข; Code.gs: อ่านชีตครั้งเดียว/เปิดสเปรดชีตครั้งเดียวต่อการเรียก, แก้ไขแถวโดยอ่านเฉพาะคอลัมน์ id แล้วเขียนทั้งแถวครั้งเดียว, getPurchaseOptions อ่านหมวดครั้งเดียว
v1.7 - จัดการข้อมูล > กลุ่มสินค้า: เพิ่มกลุ่มสินค้าล่วงหน้าได้ (เลือกหมวด + ชื่อ) ไม่ต้องรอบันทึกซื้อ เพื่อให้ OCR จับคู่ได้ทันที
v1.7 - รวมหน่วยซื้อ/หน่วยขายเป็นแท็บ "หน่วย" เดียว (เพิ่ม/เปลี่ยนชื่อ/รวม/ลบ ทำงานกับทั้งสองฝั่งพร้อมกัน); หน้าบันทึกซื้อมีช่อง "ขายหน่วยเดียวกับที่ซื้อ" (ค่าเริ่มต้น) ซ่อนเรโชและหน่วยขาย ระบบใส่เรโช=1 ให้ ถ้าสินค้าเคยบันทึกต่างหน่วยหรือ OCR อ่านได้ต่างหน่วยจะเปิดช่องเรโชให้อัตโนมัติ (โครงสร้างชีตเดิมไม่เปลี่ยน)
v1.7 - ปุ่มรีเฟรชมุมขวาบนใช้งานได้ทุกหน้า: จัดการข้อมูล=โหลดแท็บปัจจุบันใหม่, ซื้อสินค้า>ประวัติ=โหลดประวัติใหม่, ซื้อสินค้า>บันทึกซื้อ=โหลดรายการสินค้า/ร้านค้า/หน่วยใหม่ (ไม่ล้างฟอร์มที่กรอกอยู่), มีไอคอนหมุนขณะโหลด
v1.8 - ไอคอนบนหน้าจอหลักมือถือผ่าน GitHub Pages (PWA wrapper): github-pages/index.html + manifest.webmanifest + sw.js + icons/
v1.8 - หน้า "เพิ่มเติม" มีปุ่ม "เพิ่มไอคอนลงหน้าจอหลัก" (Android Chrome กดติดตั้งได้เลย / iPhone แสดงวิธี แชร์ > เพิ่มไปยังหน้าจอโฮม / ถ้าเปิดไม่ผ่านหน้า GitHub จะแสดงลิงก์ให้เปิด); กดไอคอนค้างมีทางลัด บันทึกซื้อ / ประวัติซื้อ / จัดการข้อมูล (Code.gs: doGet รับ ?go=, Index.html: startView)
วิธีติดตั้งไอคอน: 1) Apps Script > Deploy เวอร์ชันใหม่ แล้วคัดลอกลิงก์ Web App (ลงท้ายด้วย /exec) 2) เปิด github-pages/index.html ใส่ลิงก์ในบรรทัด APP_URL 3) อัปโหลดทุกไฟล์ในโฟลเดอร์ github-pages (index.html, manifest.webmanifest, sw.js, ocr-reader.html, โฟลเดอร์ icons) ไปไว้ที่ root ของ repo SmartStockLite แล้วรอ GitHub Pages อัปเดต 1-2 นาที 4) เปิด https://kunjay-eng.github.io/SmartStockLite/ บนมือถือ > เมนู เพิ่มเติม > เพิ่มไอคอนลงหน้าจอหลัก (iPhone ต้องใช้ Safari)
หมายเหตุ: ปุ่มติดตั้งใช้ได้เมื่อเปิดผ่านลิงก์ GitHub Pages ไม่ใช่ลิงก์ script.google.com โดยตรง; หน้า OCR เปิดเป็นหน้าต่างแยก ถ้าบน iPhone เปิดจากไอคอนแล้ว OCR ส่งผลกลับไม่ได้ ให้เปิดผ่าน Safari แทน
