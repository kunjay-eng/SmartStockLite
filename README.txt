หน้าสินค้า: การ์ดรายการแสดงป้าย "คงเหลือ N" (เขียว/แดงถ้า 0 หรือติดลบ) หรือ "ไม่นับสต๊อก"; หน้ารายละเอียด เพิ่มการ์ด "สต๊อกสินค้า" มีสวิตช์ นับสต๊อก/ไม่นับ, ซื้อเข้า/เบิกออก/คงเหลือ, เบิกออกตามช่องทาง (รวมทั้งหมด) และปุ่ม "เบิกสินค้านี้" (ข้ามไปหน้าเบิกพร้อมเลือกสินค้าให้); การ์ดตัวเลือกสินค้าแสดง ซื้อเข้า/เบิกออก/คงเหลือ ต่อตัวเลือก

(2) สแกนบาร์โค้ด: ปุ่มสแกนที่ช่องค้นหาหน้าสินค้า, หน้าเบิกสินค้า (สแกนเจอ = เพิ่มรายการพร้อมเลือกตัวเลือกให้ สแกนซ้ำ = จำนวน +1; ไม่เจอหรือสินค้าไม่นับสต๊อกจะแจ้งเตือน), หน้าซื้อสินค้า (สแกนเจอ = เลือกหมวด/กลุ่ม/ตัวเลือกให้) หน้าต่างสแกนมี 3 ทาง: กล้องสด > ถ่ายรูปบาร์โค้ด (ถ้าเปิดกล้องในหน้านี้ไม่ได้) > พิมพ์/ยิงรหัสด้วยเครื่องยิงบาร์โค้ด

v1.28 - สแกนบาร์โค้ดผ่าน GitHub Pages (แก้ปัญหา Apps Script บล็อกกล้องสด): ปุ่มสแกนทุกจุด (สินค้า / เบิกสินค้า / ซื้อสินค้า / พิมพ์ป้ายบาร์โค้ด) เปิดหน้า github-pages/barcode-scanner.html เป็นหน้าต่างแยก แล้วส่งรหัสกลับมาด้วย postMessage (แบบเดียวกับหน้า OCR) ถ้าเบราว์เซอร์บล็อก pop-up จะใช้หน้าต่างสแกนเดิมในแอป (พิมพ์/ยิงรหัส) แทน
หน้า barcode-scanner.html: อ่าน EAN-13 / EAN-8 / UPC-A / UPC-E / Code 128 / Code 39; ใช้ BarcodeDetector ของเบราว์เซอร์ก่อน (Chrome Android) ถ้าไม่มีจะโหลด ZXing (jsdelivr @zxing/library 0.21.3) มาอ่านแทน (iPhone/Safari); มีไฟฉาย สลับกล้อง เลือกรูป พิมพ์รหัสเอง; โหมดสแกนต่อเนื่อง (หน้าเบิกสินค้า และหน้าพิมพ์ป้าย) ส่องได้ต่อเนื่องหลายชิ้น กด "เสร็จสิ้น" เมื่อครบ (ไม่ส่งซ้ำรหัสเดิมภายใน 2.5 วินาที); หน้าซื้อสินค้าและค้นหาสินค้าสแกนครั้งเดียวแล้วปิดเอง
เทียบบาร์โค้ด UPC-A (12 หลัก) กับ EAN-13 ที่ขึ้นต้น 0 ให้ตรงกันอัตโนมัติ
