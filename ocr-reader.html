อ่านรูปคำสั่งซื้อด้วย AI

อัปโหลดรูปคำสั่งซื้อ

เลือกได้หลายรูป (หน้ารายละเอียดคำสั่งซื้อ + รายการสินค้า + สรุปยอด) ผลที่อ่านได้จะแสดงให้ตรวจสอบและแก้ไขในหน้านี้ก่อนเสมอ แล้วค่อยส่งกลับไปเติมฟอร์ม — ยังไม่บันทึกอัตโนมัติ

หน้านี้ไม่ได้ถูกเปิดจากปุ่มในฟอร์ม "ซื้อสินค้า" จึงใช้อ่านรูปทดสอบได้ แต่จะส่งผลกลับไปฟอร์มไม่ได้ (คัดลอกผลลัพธ์ JSON ได้แทน)
ยังไม่มีคีย์? ขอฟรีที่ aistudio.google.com/apikey (ล็อกอิน Gmail แล้วกด Create API Key)
คีย์เก็บใน localStorage ของเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ส่งไปที่อื่นนอกจาก Google
